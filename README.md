# Telegram Daily Lotto Bot

Core bot prototype for @DailyLottoSA_Bot.

Features:
- R60 ticket price
- Numbers 1-120
- Selection deadline 17:00 Africa/Johannesburg
- Automatic daily draw at 20:00 Africa/Johannesburg
- SQLite ticket and draw history
- Admin payment-status approval command
- Winner announcement
- Selection order recorded for payout ranking

IMPORTANT:
- Do not put the bot token in source code or GitHub.
- Set BOT_TOKEN as a secret/environment variable on the hosting service.
- This package intentionally does not connect a payment gateway yet.
- Confirm that your paid lottery/draw is legally authorised before accepting real-money entries.
